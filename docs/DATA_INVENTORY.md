# PIEZO data inventory

Audit date: 2026-11-14 (workspace client date). Raw files were inspected read-only. The exact workspace file listing is in [WORKSPACE_FILE_INDEX.md](WORKSPACE_FILE_INDEX.md); this report groups related files into datasets.

## Workspace structure

The root contains the project guide, challenge context, team context PDF and `Datasets/`. There is no pre-existing application source tree. `Datasets/` contains NISAR products and browse/QA sidecars; Arizona boundary and basin layers; ADWR Groundwater Site Inventory (GWSI) exports; a USGS field-measurement export; GRACE/GRACE-FO; PRISM precipitation; ADWR supply/demand reports; two team tracking workbooks; and no data-centre facility inventory or site-specific water disclosure. The GWSI folder includes `Code_Tables/`, `Data_Tables/`, and `Shape/` packages.

## Key audit conclusions

- Both downloaded NISAR files are full-size, openable HDF5 products with exact CRS and coordinate vectors; do not infer completeness from file size alone. Their temporal separation is only about 34 seconds and they are neighboring/overlapping frames from one acquisition pass.
- The GCOV products are geocoded surface covariance/backscatter measurements, not groundwater or displacement observations.
- Verified supplemental evidence already exists for Arizona groundwater levels, wells, basin context, broad total-water-storage anomalies and precipitation. None of the available files is a Phoenix data-centre list or a water-use disclosure register.
- No large external dataset was downloaded. Primary web records were consulted for the mandatory facility feature and are linked in the evidence ledger. Remaining acquisitions/research: (1) continue facility-by-facility primary-source verification and water-disclosure search; (2) a second compatible NISAR acquisition for temporal surface-response comparison; (3) a multi-month/year PRISM or other validated rainfall series; (4) site-specific water records only where source evidence supports a claim; and (5) extract Salt River Basin supply/demand report context with page/table citations.
- The project virtual environment contains Python 3.11, FastAPI, Rasterio, h5py, NetCDF4/xarray, pyproj, Shapely, pandas, pyshp, openpyxl, pytest and HTTPX. GeoPandas/GDAL command-line tools are not required by the current processing scripts. `npm` and Node are present; the frontend production build succeeds.
